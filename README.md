# Модуль управления учётными записями пользователей (CourseProject)

Курсовой проект по проектированию и разработке серверного модуля управления пользователями на базе ASP.NET Core и Entity Framework Core.

---

## 🛠 Стек технологий и зависимости
* **Платформа:** .NET (C#)
* **Архитектура:** Разделение на слои — `UserManagement.Data` (доступ к данным) и `UserManagment.API` (сервисный слой и контроллеры).
* **СУБД:** Гибридный режим — основной **MySQL 8.0** (`usermanagement_db`) с резервным переключением на автономный **SQLite** (`usermanagement_db.sqlite`).
* **Библиотеки:** 
  * `Microsoft.EntityFrameworkCore`
  * `Microsoft.EntityFrameworkCore.Sqlite`
  * `Pomelo.EntityFrameworkCore.MySql`

---

## 🚀 Инструкция по установке и запуску

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com
   ```
2. **Открытие проекта:**
   * Откройте файл решения `UserManagment.slnx` в Visual Studio.
   * Назначьте проект **`UserManagment.API`** в качестве запускаемого (*Set as Startup Project*).
3. **Запуск приложения:**
   * Запустите проект (`Ctrl + F5` или `F5`).
   * При наличии запущенной локальной службы MySQL (порт 3306) в консоли появится запрос пароля пользователя `root`.
   * **Ввод пароля:** введите пароль от СУБД для работы с MySQL либо нажмите **Enter** на пустой строке для автоматического перехода на локальную базу данных SQLite.
4. **Тестирование эндпоинтов:**
   * Откройте файл `UserManagment.API.http` в Visual Studio и выполните готовые сценарии HTTP-запросов.

## 📌 Текущее состояние проекта
* [x] **Настройка хранилища:** Автоматическое создание схемы БД (`EnsureCreated`) и сидинг стартовых учетных записей (`admin`, `ivan_petrov`).
* [x] **Базовый CRUD:** Реализованы создание, просмотр, обновление и удаление учетных записей.
* [x] **Мягкое и жесткое удаление:**
  * Блокировка / деактивация (`PUT /api/users/{id}/block`)
  * Разблокировка (`PUT /api/users/{id}/unblock`)
  * Физическое удаление (`DELETE /api/users/{id}`)
* [x] **Архитектурное разделение (Этап 3):** Бизнес-логика и правила валидации перенесены из контроллера в сервисный слой (`IUserService` / `UserService`).
* [x] **Поиск и фильтрация:** Поддержка query-параметров в `GET /api/users?search={query}&isActive={true|false}`.
* [x] **Безопасность конфигурации:** Пароль от СУБД исключен из `appsettings.json` и запрашивается интерактивно при старте.
