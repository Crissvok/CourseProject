4. Сделать логирование/журнал действий

УХАХАХАХАХ:
Мы продолжаем разработку курсового проекта на C# / ASP.NET Core: «Модуль управления учётными записями пользователей» (репозиторий CourseProject/UserManagment).
Текущее состояние архитектуры:
1. Стек: .NET, Entity Framework Core, MySQL (usermanagement_db) + резервный SQLite (usermanagement_db.sqlite).
2. Проекты: UserManagement.Data (модель User, AppDbContext) и UserManagment.API (контроллеры, сервисы).
3. Разделение слоев (Этап 3): Бизнес-логика вынесена из UsersController в сервисный слой IUserService / UserService. Реализованы CRUD-методы, поиск и фильтрация по search и isActive, а также soft-delete (/block, /unblock) и hard-delete (DELETE).
4. Program.cs: Настроен автоматический выбор БД (проверка порта 3306) и консольный ввод пароля root для MySQL.
