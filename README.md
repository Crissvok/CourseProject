# Модуль управления учётными записями пользователей (CourseProject)
Реализовать создание и редактирование учетных записей, блокировку пользователя, назначение роли и проверку доступа к отдельным функциям. Предусмотреть поиск пользователей и проверку корректности вводимых данных.
Курсовой проект по проектированию и разработке серверного модуля управления пользователями на базе ASP.NET Core и Entity Framework Core.
